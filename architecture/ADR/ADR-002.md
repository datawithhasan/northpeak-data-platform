## ADR-002: Customer PII Handling in Silver Layer

**Status:** Accepted

**Context:**
The Bronze `customers` table contains PII (`first_name`, `last_name`, `email`, `phone`,
`date_of_birth`, `postcode`). Silver/Gold layers are queried by a broader audience
(analysts, BI tools), so raw PII should not be propagated beyond Bronze.

Initial approach considered: hash each PII field individually (SHA-256) and carry the
hashed columns into Silver. Reviewed with a senior data engineer, who recommended
against this — see Decision below.

**Decision:**
- Drop `first_name`, `last_name`, `email`, `phone`, `date_of_birth`, and `postcode`
  entirely when transforming Bronze → Silver. They are not hashed or masked — they are
  simply excluded from Silver and Gold.
- `customer_id` is retained as-is and used as the join key across all Silver/Gold
  tables (orders, loyalty transactions, DC movements already reference it this way).
- Two derived, non-identifying fields are added in Silver instead:
  - `age_band` — bucketed from `date_of_birth` (e.g. "25-34")
  - `region` — derived from `postcode` (e.g. "Greater London")
- Raw PII remains available only in Bronze, with restricted access, for cases such as
  GDPR Subject Access Requests.

**Alternatives Considered:**
- *Field-level hashing (SHA-256):* Rejected — would require hashing multiple PII
  columns individually, adding unnecessary complexity when a single surrogate key
  (`customer_id`) already satisfies the join/grouping requirement. Plain SHA-256 is
  also vulnerable to rainbow-table attacks on low-entropy values like postcodes and
  emails; HMAC-SHA-256 with a separately-stored key would be required to mitigate this,
  adding further complexity with no added analytical value.

**Consequences:**
- Smaller attack surface in Silver/Gold — no PII-shaped columns exist downstream.
- Satisfies GDPR data minimization (only non-identifying data is exposed broadly).
- Any request requiring the real identity (support, SAR) must go through a separate,
  access-controlled query against Bronze.
